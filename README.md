# เกษมฟาร์ม — เครื่องมือคำนวณฟาร์มกุ้ง

เว็บแอปหน้าเดียว (single-page HTML) สำหรับคำนวณอาหารกุ้ง วางแผนแบ่งจับ คำนวณ ADG / PDG / FCR และสุ่มไซส์กุ้ง

## วิธีใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

## เผยแพร่บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด
2. ไปที่ Settings → Pages
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะออนไลน์ที่ `https://<username>.github.io/<repo-name>/`
