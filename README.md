<h1 align="center">เกษมฟาร์ม — เครื่องมือคำนวณฟาร์มกุ้ง</h1>

เว็บแอปหน้าเดียว (single-file, HTML + CSS + JavaScript ล้วน) สำหรับคำนวณงานประจำวันของฟาร์มกุ้ง ใช้งานบนมือถือเป็นหลัก ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล และไม่ส่งข้อมูลออกไปที่ไหน

## ฟังก์ชัน

| แท็บ | ใช้ทำอะไร |
| --- | --- |
| คำนวณอาหาร | คำนวณปริมาณอาหารจากจำนวนกุ้ง อัตรารอด และขนาดกุ้ง |
| แผนแบ่งจับ | วางแผนการแบ่งจับ |
| แผนย้าย | วางแผนการย้ายกุ้ง |
| ADG / PDG | คำนวณอัตราการเติบโต |
| FCR | คำนวณอัตราแลกเนื้อ |
| สุ่มไซส์ | บันทึกผลสุ่มไซส์กุ้ง และบันทึกผลเป็นรูปภาพเพื่อแชร์ |

## วิธีใช้งาน

**ใช้บนเครื่อง** — ดาวน์โหลดหรือ clone แล้วเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
# เปิด index.html ในเบราว์เซอร์
```

**ใช้บนมือถือ** — เปิดลิงก์ GitHub Pages (ด้านล่าง) แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนเหมือนแอป

## เผยแพร่ด้วย GitHub Pages

1. อัปโหลดโปรเจกต์นี้ขึ้น GitHub repository
2. ไปที่ **Settings → Pages**
3. ที่ **Build and deployment** เลือก **Source: Deploy from a branch**
4. เลือก Branch: `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

## โครงสร้างไฟล์

```
.
├── index.html      # ตัวแอปทั้งหมด (โลโก้ฝังเป็น base64 ในไฟล์ จึงส่งไฟล์เดียวก็ใช้งานได้)
├── assets/
│   └── logo.jpg    # โลโก้ต้นฉบับ (ใช้ใน README)
├── .nojekyll       # ให้ GitHub Pages เสิร์ฟไฟล์ตรงๆ ไม่ผ่าน Jekyll
├── .gitignore
└── README.md
```

## หมายเหตุ

- ฟอนต์ (Noto Sans Thai, Noto Serif Thai, Dancing Script) โหลดจาก Google Fonts
- ปุ่มบันทึกผลสุ่มไซส์เป็นรูปภาพใช้ไลบรารี [html2canvas](https://html2canvas.hertzen.com/) จาก cdnjs — ต้องมีอินเทอร์เน็ตตอนกดบันทึกรูป ส่วนการคำนวณอื่นๆ ใช้ออฟไลน์ได้ถ้าโหลดหน้าเว็บไว้แล้ว
- ผลการคำนวณเป็นค่าประมาณเพื่อช่วยวางแผน ควรใช้ร่วมกับประสบการณ์และหน้างานจริง
